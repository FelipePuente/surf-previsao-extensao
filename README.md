# Surf Forecast RJ - Chrome Extension 🏄‍♂️

Extensão do Google Chrome para monitoramento das condições de surf, swell, vento e gráfico de marés em tempo real no Rio de Janeiro.

## 🌊 Picos inclusos
- Arpoador, Praia do Diabo, Copacabana (P5 e P6), Leme, Grumari, Prainha, Recreio e Barra da Tijuca.

## 💻 Como instalar no Chrome
1. Ative o **Modo do Desenvolvedor** em `chrome://extensions`.
2. Clique em **Carregar sem compactação** e selecione esta pasta.
